# E-Rechnung-Eingang

Prüfdienst und Eingangs-Workflow für elektronische Rechnungen (XRechnung, ZUGFeRD): Validierung mit dem
KoSIT-Validator, Feldextraktion nach EN 16931, Archivname, Freigabe in Dataverse und Power Automate.
Im Aufbau (Meilenstein 1: Prüfdienst). English version: [README.en.md](README.en.md).
